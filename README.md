Fire-Rescue-Rover (FRR): Project Overview

Fire-Rescue-Rover (FRR) is an autonomous mobile robot designed using the Pioneer 3-AT platform in Webots.

The system simulates a fire-rescue scenario where the robot must:

1. Explore an unknown indoor environment
2. Detect a critical object (represented by a red object)
3. Navigate toward and retrieve the object
4. Safely exit the environment
5. Avoid obstacles and recover from failures autonomously
